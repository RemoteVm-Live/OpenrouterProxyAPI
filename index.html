پروکسی امن و سریع برای OpenRouter

از این آدرس به عنوان Base URL در برنامه‌ها و کدهای خود استفاده کنید.

https://proxy.yidaki.ir/v1
برای کپی کردن کلیک کنید
نمونه دستور cURL
curl https://proxy.yidaki.ir/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-or-v1-YOUR_API_KEY" \
  -d '{
    "model": "openai/gpt-4o",
    "messages": [
      {"role": "user", "content": "سلام!"}
    ]
  }'
نمونه کد Python
from openai import OpenAI

client = OpenAI(
    base_url="https://proxy.yidaki.ir/v1",
    api_key="sk-or-v1-YOUR_API_KEY" # کلید OpenRouter
)

response = client.chat.completions.create(
    model="anthropic/claude-3.5-sonnet",
    messages=[{"role": "user", "content": "سلام!"}]
)
print(response.choices[0].message.content)
نکات مهم برای استفاده
  • حتماً از کلید API خود OpenRouter (شروع با sk-or-v1-) استفاده کنید. کلیدهای OpenAI در اینجا کار نمی‌کنند.
  • نام مدل‌ها باید مطابق با مستندات OpenRouter باشد (مثلاً openai/gpt-4o یا google/gemini-pro).
  • این پروکسی تمامی درخواست‌های مسیر /v1 را به https://openrouter.ai/api/v1 هدایت می‌کند.
